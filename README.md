Overview -
This project presents an interactive Telecom Customer Churn Analysis Dashboard developed in Power BI to analyze customer attrition, identify churn drivers, and support data-driven retention strategies.

Business Problem -
Customer churn is one of the biggest challenges in the telecommunications industry. Acquiring new customers is significantly more expensive than retaining existing ones. Therefore, understanding churn patterns and identifying high-risk customer segments is critical for improving customer loyalty and revenue.

Key Insights from the Dashboard -
•	Overall churn rate is 27.0%, with 1,732 churned customers out of 6,418 customers. 
•	Customers on Month-to-Month contracts have the highest churn rate (46.53%). 
•	Fiber Optic users show the highest churn among internet service types (41.10%). 
•	The largest churn category is Competitor, accounting for 761 churned customers. 
•	The top churn reason is Competitor had better devices (289 customers) followed by Competitor made better offer (274 customers).
